# Sample APK for Device Farm Testing

## Download

Download the AWS Device Farm sample Android app:

- [AWS Device Farm Sample App (GitHub)](https://github.com/aws-samples/aws-device-farm-sample-app-for-android)

## Build APK

1. Clone the repo
2. Open in Android Studio
3. Build → Generate APK
4. Copy APK to this folder as `app-debug.apk`

## Note

The APK file is not committed to Git (excluded in .gitignore).
